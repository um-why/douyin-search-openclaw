# 公域获客与竞品截流

用户要在抖音公域「找客户 / 挖线索 / 竞品截流 / 私域引流 / 找高意向用户」时使用。本剧本**不新增命令**，复用现有 CLI。取数成功并等进程结束后，再按下面步骤整理线索。只使用本次命令返回的数据。

与 `demand-mining.md` 的区别：本剧本产出**线索名单**（谁在问、在哪、说了什么）；需求挖掘产出**痛点/诉求聚类报告**。两者同时出现时，先追问用户要哪一种，不要擅自两边都做。

## 1. 主链路（必须按顺序）

```
阶段 A 选视频                         阶段 B 挖线索
search-cli  ──aweme_id 或 url──▶  comment-cli
(关键词 → 视频列表)                 (视频 ID → 评论 / 公开身份)
```

### 1.1 关键词搜索，定位候选视频

```bash
node src/douyin/search-cli.js --keyword "<垂直关键词>" --sort 1 --limit 20
```

- 截流场景优先 `--sort 1`（最多点赞）。
- 未指定 `--limit` 时默认 10；包月 Token 搜索最多 30。不要自作主张拉很大数量。
- 从 `results[]` 取：`aweme_id`（下游必用）、`url`、`desc`、`author_nickname`、`comment_count`、`digg_count`。

### 1.2 用视频 ID 拉评论

```bash
node src/douyin/comment-cli.js --url <aweme_id> --limit 50
```

- `--url` **可直接传**上一步的 `aweme_id` 字符串，无需拼完整 URL；传 `url` 字段也可以。
- 获客默认建议至少 50 条评论才够筛意向；用户未同意前不要擅自加大。包月评论上限 50，再多可能 `PLAN_LIMIT`。
- `status` 不是 `success` 或 `results` 为空：按 `SKILL.md` 第 8 节处理，不编造线索。

## 2. 辅助入口（可选）

| 目的 | 命令 | 然后 |
| --- | --- | --- |
| 借势热点 | `hot-cli.js` | 用热词回到 1.1 搜索 |
| 盯已知竞品主页 | `post-cli.js --url <主页或 sec_uid>` | 挑高互动作品，再用其 `aweme_id` 跑 1.2 |
| 先按词找账号 | `user-search-cli.js --keyword "..."` | 用 `author_url` / `sec_uid` 跑 post，再 1.2 |
| 看清视频文案 | `detail-cli.js --url <aweme_id>` | 只作背景，不进线索条数 |

获客主链路永远是 **search → comment**（或 post/user-search 找到视频后再 comment）。不要用用户搜索结果直接当「客户线索」——那是账号，不是评论区意向用户。

## 3. 线索字段（来自 comment-cli）

| 业务含义 | 字段 |
| --- | --- |
| 昵称 | `user_nickname` |
| 唯一标识 | `user_uid` / `user_sec_uid` |
| 地区 | `ip_label` |
| 需求/意向原文 | `text` |
| 互动热度 | `digg_count` |
| 时间 | `create_time_str`（没有则用 `create_time`，再没有写「未返回」） |

公开数据**不含**手机号、微信号等隐私联系方式。禁止编造。评论里若用户自己写下联系方式，可原文摘录并标明「用户自评」，不得补全或猜测。

向用户汇报时整理成表格或短列表即可，**不要粘贴整份评论 JSON**。

## 4. 高意向筛选（后处理）

### 4.1 选用规则

1. **必用**附录 A「通用包」。  
2. 根据本次搜索关键词 / 用户行业，**叠加**附录 B 中匹配的行业包（可多选）。  
3. 用户当场给出的补充词优先；写入样本说明。  
4. 样本说明中写明：实际启用了哪些包（如 `通用 + 家装`）。  
5. 只做子串命中，不脑补同义词；无命中时如实说「本批未见明显购买意向词」，可建议换词、换视频或加大 `--limit`（须用户同意）。

命中任一词 → 优先列入高意向线索。

### 4.2 附录 A · 通用包（默认）

`求带` / `怎么买` / `求推荐` / `多少钱` / `什么价` / `哪里买` / `咋买` / `私我` / `私聊` / `链接` / `发个链接` / `微信` / `加我` / `靠谱吗` / `是真的吗` / `有没有优惠` / `有优惠吗` / `想了解` / `怎么报名` / `怎么合作` / `代理吗` / `招代理吗`

### 4.3 附录 B · 行业包（按需叠加）

**家装 / 装修**  
`量房` / `报价` / `设计费` / `全包` / `半包` / `施工周期` / `哪家靠谱` / `避坑` / `样板间` / `装修公司`

**教育 / 培训 / 留学**  
`学费` / `报名` / `课时` / `试听` / `班型` / `通过率` / `申请` / `中介` / `顾问` / `课程大纲`

**母婴 / 亲子**  
`月龄` / `适用年龄` / `会不会过敏` / `能用吗` / `囤货` / `代购` / `正品吗` / `断奶` / `辅食`

**美妆 / 个护**  
`色号` / `肤质` / `敏感肌` / `成分` / `正品` / `专柜` / `空瓶` / `种草` / `拔草` / `回购`

未列出的行业：只用通用包；可在样本说明写「无匹配行业包」，或请用户补 3–8 个意向词后再筛一轮（不重跑取数，除非用户要求）。

## 5. 输出给用户的结构

按此顺序写三段：

1. **候选视频**：标题/作者/点赞或评论数/`aweme_id`（1–3 条即可）  
2. **高意向线索表**：昵称、地区、原文、`user_sec_uid`（或 uid）  
3. **样本说明**：关键词、`--limit`、实际评论条数、是否只用主评、启用的意向词包（如 `通用 + 家装`）、平台为抖音  

不要输出可执行的骚扰话术或批量私信脚本。

## 6. 合规

- 只读公开数据；不登录、不私信、不关注、不点赞。  
- 线索仅限用户授权的内部跟进；禁止二次贩卖与骚扰。  
- 结果可能落盘到技能目录 `logs/`；对外分享前建议脱敏（可去掉 uid，只留昵称与原文摘要）。  
- 调用会把关键词/链接发往 `www.guaikei.com`；TOKEN 勿泄露。
